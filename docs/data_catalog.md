# Data Catalog

## 1. `gold.dim_customers`

**Purpose:** Customer master/dimension table containing demographic, geographic, marital, and customer lifecycle information.

| Column            | Data Type    | Key / Role          | Description                                              |
| ----------------- | ------------ | ------------------- | -------------------------------------------------------- |
| `customer_key`    | bigint       | Surrogate key       | Unique warehouse identifier for a customer.              |
| `customer_id`     | int          | Business ID         | Source-system identifier for the customer.               |
| `customer_number` | nvarchar(50) | Business identifier | Customer reference/number used to identify the customer. |
| `first_name`      | nvarchar(50) | Attribute           | Customer's first name.                                   |
| `last_name`       | nvarchar(50) | Attribute           | Customer's last name.                                    |
| `country`         | nvarchar(50) | Attribute           | Country associated with the customer.                    |
| `marital_status`  | nvarchar(50) | Attribute           | Customer's marital status.                               |
| `gender`          | nvarchar(50) | Attribute           | Customer's gender.                                       |
| `birthdate`       | date         | Attribute           | Customer's date of birth.                                |
| `create_date`     | date         | Audit / Lifecycle   | Date the customer record was created.                    |

---

## 2. `gold.dim_products`

**Purpose:** Product master/dimension table containing product identification, categorization, pricing, and lifecycle information.

| Column           | Data Type    | Key / Role          | Description                                                   |
| ---------------- | ------------ | ------------------- | ------------------------------------------------------------- |
| `product_key`    | bigint       | Surrogate key       | Unique warehouse identifier for a product.                    |
| `product_id`     | int          | Business ID         | Source-system identifier for the product.                     |
| `product_number` | nvarchar(50) | Business identifier | Product number/SKU used to identify the product.              |
| `product_name`   | nvarchar(50) | Attribute           | Name or description of the product.                           |
| `category_id`    | nvarchar(50) | Classification ID   | Identifier for the product category.                          |
| `category`       | nvarchar(50) | Classification      | High-level product category.                                  |
| `subcategory`    | nvarchar(50) | Classification      | Detailed classification beneath the category.                 |
| `maintenance`    | nvarchar(50) | Attribute           | Product maintenance/service classification or indicator.      |
| `cost`           | int          | Measure / Attribute | Cost associated with the product.                             |
| `product_line`   | nvarchar(50) | Classification      | Product line or family.                                       |
| `start_date`     | date         | Lifecycle           | Date from which the product record/version becomes effective. |

---

## 3. `gold.fact_sales`

**Purpose:** Central sales fact table containing orders, products, customers, quantities, prices, and sales amounts.

| Column          | Data Type    | Key / Role     | Description                                                    |
| --------------- | ------------ | -------------- | -------------------------------------------------------------- |
| `order_number`  | nvarchar(50) | Business ID    | Identifier for the sales order.                                |
| `product_key`   | bigint       | Foreign key    | References the product associated with the sales transaction.  |
| `customer_key`  | bigint       | Foreign key    | References the customer associated with the sales transaction. |
| `order_date`    | date         | Date attribute | Date on which the order was placed.                            |
| `shipping_date` | date         | Date attribute | Date on which the order was shipped.                           |
| `due_date`      | date         | Date attribute | Expected/due date associated with the order.                   |
| `sales_amount`  | int          | Measure        | Monetary sales value generated by the transaction/line.        |
| `quantity`      | int          | Measure        | Number of units sold.                                          |
| `price`         | int          | Measure        | Unit selling price recorded for the sales line.                |

### Relationships

| From                      | To                           | Relationship |
| ------------------------- | ---------------------------- | ------------ |
| `fact_sales.customer_key` | `dim_customers.customer_key` | Many-to-one  |
| `fact_sales.product_key`  | `dim_products.product_key`   | Many-to-one  |
